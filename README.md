# STREAM IT — קולנוע, סדרות ושידורים חיים בעברית (v5.0 Encrypted Edition)

מערכת סטרימינג עצמאית ומוצפנת בעברית מלאה (`RTL`) המשלבת:
- **הפרדת חשבונות מאובטחת (Username + Password)** עם הצפנת **AES-256-GCM + PBKDF2-SHA256**.
- **עד 10 יוזרים (פרופילים) נפרדים בכל חשבון** — לכל פרופיל רשימת צפייה אישית, המשך צפייה והגדרות נפרדות.
- **חיבור טלגרם אופציונלי בלבד לכל יוזר בנפרד** (כבוי כברירת מחדל — מי שרוצה מחבר במצב סרטים בלבד ללא גישה לצ'אטים, ומי שלא רוצה עובד ללא טלגרם).
- **מנהרת VPN ופרטיות מובנית (`DNS-over-HTTPS 1.1.1.1` + `Encrypted Relay` + `WebRTC IP Leak Shield`)**.
- **0% מידע אישי ו-0% חיבור לרשת ביתית**.
